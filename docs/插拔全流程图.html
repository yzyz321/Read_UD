U盘插拔全流程图（UdiskTools v1.0）
主线：插盘检测 → AUTO/MANUAL 分流 → 整任务四步（识别·复制·读取判定·测试）→ 结果显示 → 拔出复位 → 循环；判断条件见橙色菱形

图 1 · 主流程：插入 → 执行 → 拔出（循环）

核心分流：只有「监控开启 或 AUTORUN=1」插盘才自动执行；否则停在 MANUAL 等手动按钮。

子图 A · 整任务线程（自动 / 手动共用，串行四步）

右侧灰/红框为「跳过（记日志）」与「错误」出口，最后统一汇入任务结束；任务执行中新请求被忽略（g_running 互斥）。

子图 B · 复制文件 op_write（条件链）

五道前置判断逐级放行；任一不满足即从右侧出口返回任务；复制循环内含 MD5 校验判断。

子图 C · 读取 + 判定 op_read（核心校验）

命中文件三重筛选：有没有 → 是否唯一（STRICT）→ 规则链（READRULE）；PASS/FAIL 直接驱动绿/红徽标。

子图 D · 格式化 op_format（仅手动按钮触发）

自动整任务不含格式化；CONFIRM=1 时先弹窗，操作员取消即终止。

配置键 → 判断位置对照表

「使能键决定按钮与步骤、AUTORUN/监控决定自动与否、AUTO_* 只裁剪自动流程内的步骤」——三层职责分离。

配置键判断位置取值与作用
（监控开关）图1 · 菱形②点〔开始监控〕=1；与 AUTORUN 任一为真 → 1104 显示 AUTO，插盘自动执行整任务
AUTORUN图1 · 菱形②1=插盘即自动执行（无需开监控）；0=需先开监控或手动
AUTO_COPY子图A · 菱形②自动流程内是否复制：手动触发总是复制；自动触发须 1 才执行（0=仅手动点〔复制〕）
AUTO_TEST子图A · 菱形④自动流程内是否读写测试：手动触发总是执行；自动触发须 1（默认 0）
ENABLE_USBINFO子图A · 步骤①0=跳过 USB 识别（卷标/序列号/速度）
ENABLE_WRITE子图B · 菱形①0=跳过写入，且主界面〔复制〕按钮置灰
WRITEMODE子图B · 菱形②COPY=简单复制；PROCESSED=v1.x 预留（本次跳过）
HASH子图B · 菱形⑥md5=每个文件复制后做源/目标 MD5 比对，不一致计失败
ENABLE_READ子图C · 菱形①0=跳过读取，且〔读取校验〕按钮置灰
READFILE子图C · 菱形②未配置→跳过；支持子目录前缀（如 SYSTEM\PAW6K-LSN）
MATCH_POLICY子图C · 菱形④NEWEST=最新时间；FIRST=首个；STRICT=多命中直接 FAIL
READPATTERN子图C · 步骤③WILDCARD 通配；REGEX 为后续版本（暂按 WILDCARD）
READRULE子图C · 菱形⑤MIN_LEN:n 最小长度；MUST_CONTAIN:k 必含关键字；全通过=PASS（绿）
ENABLE_FORMAT子图D · 菱形①0=〔格式化〕按钮置灰
CONFIRM子图D · 菱形②1=格式化前弹窗确认（取消则终止）
FILESYSTEM / VOLUME子图D · 步骤⑤格式化文件系统与卷标（FAT32/EXFAT）
SRCPATH / DSTPATH子图B · 菱形③④写入源与目标；源目录不存在或无匹配文件即报错
