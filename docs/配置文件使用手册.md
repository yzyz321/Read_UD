# UdiskTools 配置文件使用手册

适用软件版本：v1.2.0　配置文件：`UdiskTools.ini`（与 UdiskTools.exe 同目录）　配置文件版本：见 `[TOOLSINFO] VERSION`（与软件版本独立）

---

## 1. 基本约定

| 项目 | 说明 |
|---|---|
| 文件名 | 必须为 `UdiskTools.ini`，与 exe 同目录 |
| 文件不存在 | 启动时弹窗由用户选择：**是**=以内置默认配置运行（自动在程序目录生成 `UdiskTools.ini`，内容与内置默认一致，可随后在配置窗口修改）；**否**=直接退出程序。`--check-ini`（CLI）下文件不存在仍返回失败码 1，不弹窗 |
| 编码 | 统一自动识别：UTF-8（推荐，有/无 BOM）/ UTF-16LE、UTF-16BE（有 BOM 或零字节启发式）/ ANSI-GBK；**损坏的 UTF-8（少量非法字节）与二进制文件会被拒绝并写日志原因**，不会静默按 GBK 读出乱码 |
| 注释 | 行首（允许前导空白）的 `;`，或**前一个字符是空格/制表符**的 `;`，其后的内容为注释；其余 `;` 属于值内容（如 `READRULE=MUST_CONTAIN:8685;MIN_LEN:10` 的分号规则链） |
| 缺失键 | 未写的键取默认值，程序不会报错 |
| 修改生效 | 配置窗口保存后、或切换机型下拉框后**立即重载**，无需重启；重载失败会提示并保留旧配置 |

## 2. 全局节 [TOOLSINFO]

| 键 | 说明 | 默认 |
|---|---|---|
| `TITLE` | 窗口标题 | UdiskTools |
| `VERSION` | **配置文件版本**（标题栏显示 `v<VERSION>`；**不是软件版本**，软件版本见 §2.1） | 1.0.0 |
| `ADMINPASS` | 配置窗口管理员密码；**留空=无密码保护（配置窗口仅只读，不可编辑）** | 空 |
| `PRJNUM` | 机型数量 | — |
| `PRJNAMEn` | 机型 n 的**内部键**，必须与下方机型节名完全一致；程序结构依赖，**永不改动** | — |
| `DISPLAYNAMEn` | 机型 n 的**显示名**（下拉框/配置窗口显示）；可随时修改，不影响程序 | 缺省回退内部键 |
| `DEFAULTMODEL` | 启动时默认选中的机型（内部键） | 第 1 个机型 |
| `TOPMOST` | **主窗口置顶初始状态**：1=启动即置顶（复选框默认勾选）；0=启动不置顶（仍可点"窗口置顶"复选框切换）；其它值按缺省 1 处理并告警 | `1` |

### 2.1 软件版本与标题显示

程序有**两套相互独立的版本号**：

| 项 | 说明 |
|---|---|
| **软件版本** | 程序自身版本（`src/version.h` `APP_VERSION`，当前 **1.2.0**）：`--version` 显示“软件 v1.2.0（FileVersion 1.2.0.0）”与构建时间；启动日志同样显示“软件 v1.2.0”。升级程序只改变软件版本。 |
| **配置文件版本** | 由本 ini 的 `[TOOLSINFO] VERSION` 决定（示例配置为 `1.0.0`），仅表示配置内容版本；`--check-ini` 输出 `配置版本 ...`；升级程序**不会**自动修改它（需要现场按配置变更自行维护）。 |
| **窗口标题** | `<TITLE> v<配置文件版本>（软件 v<软件版本>）`，例如 `U盘拷盘工具 v1.0.0（软件 v1.2.0）`；`VERSION` 留空时显示 `<TITLE>（软件 v1.2.0）`。 |

## 3. 机型节（每机型一个节，节名 = 对应 PRJNAMEn）

### 3.1 功能开关（0=禁用：按钮置灰、自动模式跳过）

| 键 | 说明 |
|---|---|
| `ENABLE_READ` | 读取（读取+判定+显示） |
| `ENABLE_WRITE` | 写入（复制文件）；同时控制"写入标签/升级"按钮 |
| `ENABLE_FORMAT` | 格式化 |
| `ENABLE_USBINFO` | USB 通讯模式识别 |
| `AUTORUN` | **1=插入 U 盘立即自动执行任务**；0=仅在"开始监控"开启时插盘自动执行 |
| `AUTO_COPY` | **自动复制开关**：1=自动触发时复制文件（默认 1）；0=自动触发时不复制，只手动点 [复制] 按钮 |
| `AUTO_TEST` | **自动测试开关**：1=自动触发时执行读写测试；0=不自动测试，只手动点 [读写测试]（默认 0） |

> `AUTO_COPY` / `AUTO_TEST` 只影响**自动触发**（插盘）时的动作集合；手动点击按钮不受这两个开关限制。
>
> 判定政策：以上 `ENABLE_*` 置 0、`AUTO_COPY/AUTO_TEST` 自动裁剪、`READFILE`/`READRULE` 留空，都属于**按配置正常屏蔽**——对应步骤跳过，但**任务仍按成功对待**（日志记录跳过步数）；程序自行降级/未实现/无法校验则判失败，详见 3.7。

### 3.2 按钮 ↔ 配置项 ↔ 自动/手动 对照表

| 按钮（控件 ID） | 执行内容 | 相关配置项 | 自动触发时是否执行 |
|---|---|---|---|
| **开始** `IDC_BTN_START 1002` | 完整任务序列：USB 识别 → 复制 → 读取判定 → 读写测试 | `ENABLE_*` / `SRCPATH` / `READFILE` / `READRULE` | —（手动按钮） |
| **停止** `IDC_BTN_STOP 1003` | 中止当前任务：任务执行期间按钮可用；复制过程中可立即取消；格式化在 `FormatEx` 开始后不可中止，但确认阶段按停止会取消本次格式化 | — | — |
| **复制**（默认名，可配置为“升级”）`IDC_BTN_WRITELABEL 1006` | 仅复制：`SRCPATH→DSTPATH` + MD5 校验，结果显示 `Copy Complete!/Copy Failure!` | `ENABLE_WRITE`、`WRITEMODE=COPY`、`SRCPATH`、`DSTPATH`、`HASH` | 由 `AUTO_COPY` 决定（自动流程内含复制） |
| **读取校验** `IDC_BTN_READCHECK 1015` | 仅读取：通配符匹配 `READFILE` → 读内容 → `READRULE` 判定（关键字/最小长度），结果显示 PASS/FAIL | `ENABLE_READ`、`READFILE`、`MATCH_POLICY`、`READRULE` | 自动流程**总是执行**（核心校验，由 `ENABLE_READ` 控制） |
| **读写测试** `IDC_BTN_RWTEST 1016` | 仅测试：写 8MB→回读→MD5 比对→速率 | 无（通用） | 由 `AUTO_TEST` 决定（1=自动执行） |
| **格式化** `IDC_BTN_FORMAT 1004` | 格式化（FAT32/EXFAT），**每次都必须人工确认**（确认框显示盘符/卷标/容量/卷序列号/VID/SN）；确认后复核设备身份，盘已更换则取消；完成后按 `VOLUME` 写卷标 | `ENABLE_FORMAT`、`CONFIRM`（兼容保留）、`FILESYSTEM`、`VOLUME` | 自动流程**不执行**（防误格式化，仅手动） |
| **读取标签** `IDC_BTN_READLABEL 1005` | 读取卷标/文件系统/序列号/容量并显示 | 无 | 自动流程以 USB 识别代替显示 |
| **开始监控 / 停止监控** `1010/1011` | 开启后插盘自动执行完整任务 | 与 `AUTORUN=1` 等效的触发源 | 触发自动流程 |
| **配置** `IDC_BTN_CONFIG 1007` | 打开配置窗口（只读/解锁编辑/恢复默认） | `ADMINPASS` | — |
| **清屏** `IDC_BTN_CLEARCMD 1014` | 清空 CMD-A 显示（日志文件保留） | — | — |

> **自动流程动作集合**（插盘时）：USB 识别（`ENABLE_USBINFO`）→ 复制（`AUTO_COPY=1` 且 `ENABLE_WRITE=1`）→ 读取判定（`ENABLE_READ=1`，总是执行）→ 读写测试（`AUTO_TEST=1`）。格式化永远不自动执行。

### 3.3 按钮显示名（可省略）

| 键 | 默认名 |
|---|---|
| `BTN_START` / `BTN_STOP` / `BTN_FORMAT` / `BTN_READLABEL` / `BTN_WRITELABEL` | 开始 / 停止 / 格式化 / 读取标签 / 写入标签 |

> 说明：`BTN_*` 只改界面文字；内部控件 ID 与日志记录的操作名不变。
> `BTN_WRITELABEL`（如显示为"升级"）实际执行**复制文件**操作。

### 3.4 写入（复制）配置

| 键 | 说明 |
|---|---|
| `WRITEMODE` | `COPY`=简单复制；`PROCESSED` 未实现：配置后复制步骤**判失败**（不得按成功处理） |
| `SRCPATH` | 复制源路径。**支持绝对路径**（`D:\src\*.img`）**和相对路径**（相对 exe 所在目录，如 `.\copy_src\*.*`）；支持通配符 `*` `?` |
| `DSTPATH` | U 盘内目标目录（`\`=根目录）。**目录不存在时自动逐级建立** |
| `HASH` | 校验算法：**仅支持 `md5`**（其它值判失败）。复制后逐文件比对；不一致会自动删除目标并**重试复制一次**，仍不一致则删除坏副本并判失败；MD5 无法计算也判失败 |

> **覆盖规则**：目标文件已存在时**自动覆盖**（CMD-A 记录"已存在，覆盖"）。

### 3.5 读取（判定）配置

| 键 | 说明 |
|---|---|
| `READFILE` | U 盘上要读取的文件；**支持子目录**（`SYSTEM\PAW6K-LSN`）与**通配符**（`8685????.txt`：固定格式+可变部分，`SYSTEM\*.txt` 两者可组合）；留空=跳过读取 |
| `MATCH_POLICY` | 多个命中时：`NEWEST` 取最新 / `FIRST` 取第一个 / `STRICT` 多命中报错列出全部 |
| `READPATTERN` | `WILDCARD`（`*` `?` 通配符，推荐）；`REGEX` **未实现**：配置为 REGEX 时读取判定会失败（不会再静默降级为 WILDCARD） |
| `READRULE` | 判定规则链，分号分隔：`MUST_CONTAIN:关键字`（须包含）、`MIN_LEN:10`（最小长度）。判定 PASS 才显示内容并亮绿徽标，FAIL 显示原因并亮红徽标。**分号 `;` 前不要加空格**（加空格会被当作注释起点，只有第一条规则生效）；推荐写法 `MUST_CONTAIN:8685;MIN_LEN:10`。留空=不做内容规则（按配置正常屏蔽）；**含未识别规则名（拼写错误）会判失败** |

> 命中的可变部分（`?` 对应字符）自动捕获为 `${MATCH_1}`，输出在 CMD-A 日志。

### 3.6 格式化配置

| 键 | 说明 |
|---|---|
| `CONFIRM` | 兼容保留：格式化前**始终强制**弹窗二次确认（置 0 也不会跳过确认，仅写一条告警日志） |
| `FILESYSTEM` | `FAT32` / `EXFAT`（其它值在确认前校验阶段判失败，不会格式化） |
| `VOLUME` | **格式化完成后**写入的卷标；留空=不改卷标。**校验规则：≤11 个字符（FAT32/exFAT），禁止 `\ / : * ? " < > |` 与控制字符；不合法会在确认前判失败**。**没有独立的"写卷标"操作** |

> **格式化安全机制（v1.0.0 修复后）**：确认前先校验 `FILESYSTEM`/`VOLUME`；确认框显示目标盘的盘符、卷标、容量、文件系统、卷序列号与 VID/SN；点击确定后会再次读取设备身份并与确认前比较，若盘已被拔出或更换则取消格式化（不会调用 `FormatEx`）。任务级操作也会在每一步前复核目标盘身份，换盘后自动中止。格式化成功后自动刷新设备信息（卷标/文件系统/容量）；若配置了 `VOLUME` 但卷标写入失败会判失败并记录日志。

### 3.7 跳过与结果判定（重要）

**判定政策：按配置正常屏蔽的步骤 → 任务仍判定为成功；程序自行降级/未实现/无法校验 → 判定为失败。**

| 情形 | 归类 | 任务结果 |
|---|---|---|
| `ENABLE_READ/WRITE/FORMAT/USBINFO=0` | 按配置正常屏蔽 | 成功（日志记“按配置跳过”，并计数） |
| `READFILE` 留空（跳过读取）、`READRULE` 留空（不做内容规则） | 按配置正常屏蔽 | 成功 |
| 自动触发时 `AUTO_COPY=0` / `AUTO_TEST=0` | 按配置裁剪 | 成功（日志记“按配置跳过”） |
| `WRITEMODE=PROCESSED`（未实现） | 程序降级 | **失败** |
| `READPATTERN=REGEX`（未实现） | 程序降级 | **失败** |
| `HASH` 不是 `md5`、或 MD5 无法计算 | 无法校验 | **失败**（不会在未校验状态下报成功） |
| `READRULE` 含未识别规则（如拼写错误） | 程序自行跳过规则 | **失败** |
| 读取过程中目标盘被拔出/更换 | 数据可能失真 | **失败（本次判定作废）** |

- 任务结束日志：`=== 任务结束（成功 / 有错误 / 已停止 / 按配置跳过（未执行））：执行 N 步，按配置跳过 M 步 ===`。
- 若全部步骤都被配置屏蔽，界面显示“**按配置跳过（未执行）**”（绿色，仍属成功类别）。
- **任务执行中插入新盘**：不会清空当前任务的输出/进度；该盘记为“待处理盘”。当前任务**成功或按配置跳过**结束后，若仍处于自动模式则自动补跑；任务失败/被停止则取消补跑（避免失败循环）；待处理盘被拔出会取消。
- **读取前后设备复核**：读取文件期间若盘被拔出/更换，本次判定作废并判失败（不会给出错误的 PASS/FAIL）。

### 3.8 USB 通讯模式识别与读写测试（修复后）

- **USB 通讯模式**：通过 USB Hub 端口按 `VID/PID` 匹配链路速度（Low/Full/High/Super/Super+）；同一 `VID/PID` 存在多个设备、无权限打开集线器、或未匹配到端口时显示“未知（原因）”，**不判错误**（属信息类功能）。
- **读写测试**：优先 `FILE_FLAG_NO_BUFFERING | FILE_FLAG_WRITE_THROUGH` 直读介质（日志注明“直读介质，未走缓存”）；若平台不支持则回退缓冲模式并告警（结果可能受系统缓存影响）；测试文件带 PID、用完自动删除，删除失败记 WARN。
## 4. 路径规则汇总

1. `SRCPATH`：绝对路径与相对路径均支持（相对 = 相对 exe 所在目录）
2. `DSTPATH`：U 盘内路径；多级目录不存在时自动建立（如 `DSTPATH=data\2024\`）
3. 复制目标已存在 → 自动覆盖
4. `READFILE` 支持 U 盘内子目录路径（如 `SYSTEM\PAW6K-LSN` = 读 `U盘:\SYSTEM\PAW6K-LSN`）

## 5. 机型配置示例

```ini
; 新增一个机型的最小步骤：
; ① [TOOLSINFO] 中 PRJNUM 加 1，追加 PRJNAME5=NEWMODEL、DISPLAYNAME5=新机型
; ② 追加机型节：
[NEWMODEL]
ENABLE_READ=1
ENABLE_WRITE=1
ENABLE_FORMAT=0
ENABLE_USBINFO=1
AUTORUN=0
SRCPATH=D:\factory\fw_v2.bin      ; 绝对路径示例
DSTPATH=firmware\                 ; U 盘内 firmware 目录（自动建立）
READFILE=SN*.txt
MATCH_POLICY=NEWEST
READRULE=MUST_CONTAIN:OK;MIN_LEN:5
HASH=md5
```

## 6. 自动复制 / 自动测试如何开启

自动流程由**触发源**与**动作开关**两层控制：

**第一层：触发源（插盘是否自动开始任务）**
1. 机型节内 `AUTORUN=1` —— 插盘即自动跑
2. 或界面点“开始监控” —— 监控期间插盘自动跑

**第二层：动作开关（自动流程包含哪些动作）**
- `AUTO_COPY=1` → 自动复制文件；`0` → 不自动复制（只手动点 [复制]）
- `AUTO_TEST=1` → 自动读写测试；`0` → 不自动测试（只手动点 [读写测试]）
- 读取判定：`ENABLE_READ=1` 时**总是**执行
- 格式化：**永不自动执行**

> 手动点按钮不受 `AUTO_*` 限制（点击即明确意图）。
> 关闭自动：`AUTORUN=0` 并点“停止监控”。

## 7. 恢复默认设置

配置窗口点击 **[恢复默认设置]** 并确认后，程序会用**内嵌的默认配置**（与 `profiles/UdiskTools_default.ini` 相同，CI 会校验两者一致；ini 缺失时启动弹窗"以默认配置运行"写入的也是这份内容）覆盖 `UdiskTools.ini` 并立即重载。自定义过的机型和路径会丢失，请谨慎操作（每次覆盖前有确认弹窗，操作写入日志）。**覆盖前会先备份为 `UdiskTools.ini.bak`**；写入采用临时文件+原子替换+写后回读解析校验，任何失败都保留原 ini 并提示错误，不会截断原文件；重载失败也会提示（不再假报"已恢复"）。

## 8. 界面状态行与配置窗口

- **状态行**：`AUTO`（绿色）/ `MANUAL`（蓝色）标记 + 其后显示当前机型的 `SRCPATH` 配置值 + 右端**插拔计数器**（`IDC_STC_INSERTCOUNT 1017`）；切换机型或保存配置后立即刷新
- **插拔计数器（`IDC_STC_INSERTCOUNT 1017`）**：仅**监控开启时**计数——每插入一个 U 盘 +1（拔出不计），[停止监控] 即停止计数（数值保留）；显示"**计数:0000**"粗体 4 位数字，**超过 9999 自动回 0000 循环**；启动为 0，退出程序不保存（下次启动自动归零）；启动时已插着的盘不计入
- **标签行（`IDC_STC_LABEL 1101`）**：随插拔**实时刷新**，显示当前各盘**卷标**（多盘逐个列出；无盘显示"（无磁盘）"）；USB VID/PID/序列号**不再在界面显示**，仅由任务线程采集用于目标盘身份复核与格式化确认。[读取标签] 按钮可单独刷新为详细文本（卷标/文件系统/序列号/容量/可用空间）
- **命中文件提示行分左右**：`IDC_STC_MONFILE 1103` 为**左窗格（1502）专属**提示（第一命中文件路径）；`IDC_STC_MONFILE2 1108` 为**右窗格（1503）专属**提示（第二命中文件路径）；每次插盘同步清空
- **状态徽标（`IDC_STC_ERROR 1202`）双色**：**正常=绿字"✓ …"**（插盘时、任务完成时显示"任务完成"）；**出错=红字"✕ 出错：原因"**（标题栏加 `[!]`）；每次插盘先清掉上一盘状态再显示新盘状态
- **AUTO / MANUAL 判定依据（`IDC_STC_AUTOMODE 1104`）**：
  - **AUTO** = [开始监控] 已开启 **或** 当前机型 `AUTORUN=1` → 插盘会自动执行整任务
  - **MANUAL** = 两者皆无 → 必须手动点按钮
  - `AUTO_COPY` / `AUTO_TEST` 只决定"自动流程内做哪几步"（复制 / 读写测试），**不参与** AUTO/MANUAL 判定；手动点按钮也不会把 AUTO 改成 MANUAL
  - 每次模式变化都写入 CMD-A 日志，便于现场核对，例如 `[UI] 运行模式 AUTO（监控已开启）`、`[UI] 运行模式 AUTO（本机型 AUTORUN=1）`、`[UI] 运行模式 MANUAL（未开监控且本机型 AUTORUN=0）`
- **快捷键（`IDC_CHK_HOTKEY 1013`）**：勾选后注册 **Ctrl+Alt+T=读写测试**、**Ctrl+Alt+C=复制**（均为单操作；任务执行中按下会被忽略并记录日志）；取消勾选或退出程序时注销；注册失败会提示并自动取消勾选
- **AUTO_COPY / AUTO_TEST 灰只读状态框（`IDC_CHK_AUTO_COPY 1009` / `IDC_CHK_AUTO_TEST 1018`）**：位于窗口顶部第二行、`窗口置顶` 右侧；显示**当前机型**的 `AUTO_COPY`（缺省 1）/`AUTO_TEST`（缺省 0）配置状态（勾选/未勾选），**灰色只读、不可操作**；切换机型或保存配置后立即刷新。它们只做状态显示，不参与 AUTO/MANUAL 判定，也不能用来修改配置（修改请用配置窗口）。
- **判定规则标签（`IDC_STC_READRULE 1109`）**：位于状态行（AUTO/MANUAL + SRCPATH + 计数）下方整宽一行；当当前机型 `AUTO_TEST=1` 时显示 `判定规则：<READRULE>`，`READRULE` 为空显示 `判定规则：（未配置 READRULE）`；`AUTO_TEST=0` 时该行内容为空。仅界面展示，不改变读取判定逻辑。
- **每次插盘自动刷新**：检测到 U 盘插入时，程序先**熄灭出错徽标**（IDC_STC_ERROR 1202）、**清空 CMD-A**（IDC_EDIT_ENGINE 1401）、**复位进度条与文件内容窗格**，再开始本轮检测/任务日志——每盘信息独立，不会与上一盘混在一起（文件日志 logs\\*.log 仍完整保留全部历史）
- **进度条（`IDC_PBAR_TASK 1301`）**：前方显示"任务进度："提示（`IDC_STC_PROGTITLE 1106`），后方显示实时百分比（`IDC_STC_PROGPCT 1107`）；复制采用 `CopyFileExW` **按字节回调**推进度——复制大文件时进度条实时移动，而不是等整个文件复制完才跳一格
- **文件内容双窗格（左右并排，与 CMD 双控制台同布局）**：左窗格（`IDC_EDIT_FILE 1502`）显示**第一命中文件**内容，右窗格（`IDC_EDIT_FILE2 1503`）显示**第二命中文件**内容（仅一个命中时右窗格为空）；主窗口纵向加高，内容区**不滚动约可见 10 行**
- **CMD-B 输出区（`IDC_EDIT_IDENT 1402`）**：**预留（标识生成扩展）**——当前无内容、无入口、不参与任务；v1.0 不承诺“标识生成/按台生成 SN/MAC”功能
- **配置窗口**：键名用**下拉框**选择（自动列出当前机型全部键）；选中后——
  - 枚举型键（`ENABLE_*`、`AUTO_COPY`、`AUTO_TEST`、`AUTORUN`、`CONFIRM`、`WRITEMODE`、`MATCH_POLICY`、`READPATTERN`、`FILESYSTEM`、`HASH`）自动显示**值下拉框**，无需手输
  - 其余键（`SRCPATH`、`DSTPATH`、`READFILE`、`READRULE`、`VOLUME`、`TITLE` 等）显示**输入框**，自由填写
  - "说明："行（IDC_STC_CFGHINT）实时显示**当前选中键的简要说明**，帮助理解该键含义与可选值；按钮显示名（`BTN_*`）类键与暂未收录的键给出兜底提示（详见本手册对应章节）
  - **键名框支持手动输入**（`IDC_CFG_COMBO_KEY 3011` 为可编辑下拉）：既可从列表选择本机型已有键，也可直接键入**列表外的新键名**（如临时新增一个 `BTN_XXX` 或后续版本预留键），值输入框与新键名配合 [保存修改] 写入 ini；键入手输键名时"说明："行同步给出对应提示或兜底说明
  - **保存规则（v1.0.0 修复后）**：新键插入到**当前机型节的节尾**（不会落到文件末尾/其它机型）；保存保留文件原编码（UTF-8 有/无 BOM、UTF-16LE/BE 有/无 BOM、ANSI）、原行尾风格、其余行与行内注释；保存后自动回读校验。以下值会被拒绝并提示"保存失败"（不会写坏 ini）：含换行、首尾空白、长度 ≥512、或 `;` 前带空格（会被解析成注释）的值；键名不能含 `=`/`[`/`]`。**保存写入成功但重载失败时，日志/弹窗会明确“已写入但重载失败”，不会记成“已保存（配置已重载）”。**
- **解析告警（写入日志，不阻断启动）**：机型数 >16、单机型键数 >48、节名/键名/值超长被截断、节头缺 `]`、空节名 `[]`、超长节名、重复节名（合并）、`PRJNAME` 与节名不匹配等，均写 WARN 并说明被忽略/截断内容。

## 9. 安全说明


- `ADMINPASS` 留空时配置窗口永远只读（解锁按钮不可用）
- 密码输入框在点击“解锁编辑”后才显示；密码错误只提示（可无限重试，不做次数锁定），失败仅写日志（不含密码内容）；未解锁时配置窗口只读，[保存修改]/[恢复默认设置] 不可用
- 解锁/保存/恢复默认等操作均写入日志（不含密码内容）
- 任务启动与每一步执行前会复核目标盘身份（盘符+卷序列号+VID/SN）；格式化确认后还会再复核一次，换盘会取消格式化/中止任务
- 程序自行降级、未实现或无法校验的跳过（PROCESSED/REGEX/非 md5/未知规则/MD5 无法计算）**一律判失败**，不会以“成功”掩盖

## 10. 常见错误排查

| CMD-A 提示 | 原因 | 处理 |
|---|---|---|
| `[WRITE] 源目录不存在：D:\...\build\upgrade` | `SRCPATH` 目录名与实际不符（拼写错误/相对路径基准不是 exe 目录） | 核对目录名；相对路径**以 exe 所在目录为基准**，`.\upgrade\*.*` 即 exe 同级的 `upgrade` 文件夹 |
| `[WRITE] 源目录存在，但没有匹配文件（通配符 *.img）` | 目录在，但通配符匹配不到文件 | 检查扩展名/通配符；`*.*` 匹配所有文件 |
| `[WRITE] 源目录内没有可复制的文件` | 目录下只有子文件夹 | 把文件放进该目录，或将 `SRCPATH` 指到实际含文件的目录 |
| `[WRITE] 无法创建目标目录` | U 盘只读/被写保护、路径非法 | 检查写保护开关与 `DSTPATH` 拼写 |
| `[READ] 未找到匹配文件` | 盘内无匹配文件，或 `READFILE` 通配符/路径不符 | 核对文件名规则（如 `8685????.txt`、`SYSTEM\PAW6K-LSN`） |
| `[READ] READPATTERN=REGEX 未实现，拒绝按 WILDCARD 降级判定` | 配置了未实现的正则模式 | 改 `READPATTERN=WILDCARD` |
| `[READ] 未识别的判定规则 "..."` | `READRULE` 拼写错误或使用了不支持的规则 | 只用 `MUST_CONTAIN:` / `MIN_LEN:`（分号分隔、分号前不加空格） |
| `[WRITE] WRITEMODE=PROCESSED 未实现，不能按成功处理` | 配置了未实现模式 | 改 `WRITEMODE=COPY` |
| `[WRITE] HASH=... 未实现/不支持，拒绝在未校验状态下复制` | `HASH` 不是 md5 | 改 `HASH=md5` |
| `[WRITE]/[READ] …：设备已移除/未就绪` | 任务执行中拔盘/换盘 | 重新插好目标盘后重试；检查盘是否松动 |
| 任务结束显示“按配置跳过（未执行）” | 所有步骤都被 `ENABLE_*`/`AUTO_*`/留空配置屏蔽 | 属正常（成功类别）；需要执行请打开对应 `ENABLE_*` |
| `[FORMAT] 格式化失败` | 无权限或盘被占用 | 以管理员身份重试，关闭占用程序 |
| `[FORMAT] FILESYSTEM=... 不受支持` | `FILESYSTEM` 不是 FAT32/EXFAT | 改为 `FAT32` 或 `EXFAT`（修正后重新格式化） |
| `[FORMAT] VOLUME 卷标过长 / 包含非法字符 / 控制字符` | 卷标 >11 字符或含 `\ / : * ? " < > |` 等 | 修正 `VOLUME`（FAT32/exFAT 最多 11 字符） |
| `[FORMAT] 格式化完成但卷标写入失败` | 盘被占用/权限不足/盘刚格式化未就绪 | 重新插拔后重试；或先用系统格式化确认盘状态 |
| `[USBINFO] 通讯模式：未知（原因…）` | 非 USB 设备、同 VID/PID 多设备、无权限打开集线器、未匹配到端口 | 属信息类提示不判错误；单盘测试时重试或检查 USB 连接 |
| `[LABEL] 无法读取卷信息（盘未格式化或未就绪）` | 目标盘 RAW/未就绪/已拔出 | 确认盘已就绪；RAW 盘需先格式化 |
| `[WRITE] MD5 校验无法完成 / MD5 重试后仍不一致` | 校验阶段文件读取错误，或复制结果确实不一致 | 检查盘/源文件是否稳定；任务已按失败处理并删除坏副本 |
| `[RWTEST] ...（缓冲模式）` | 当前环境不支持 NO_BUFFERING（多为网络盘/特殊卷） | 结果可能受系统缓存影响；U 盘本地卷应显示“直读介质，未走缓存” |
| `[CFG] 加载失败：无法读取/解码 ini` | 文件不存在、损坏 UTF-8/二进制、超过 16MB、被独占占用 | 用文本编辑器另存为 UTF-8（推荐）或 UTF-16/GBK；查看日志中的具体原因/偏移 |
| `[CFG] 第 N 行 … 已忽略/截断/合并` | ini 超限（>16 机型/48 键/键名 64/值 512）或节头畸形、空节名、重复节名 | 按 WARN 提示修正；重复节会合并（后出现的键覆盖） |
| `[CFG] ini 已写入但重载失败` | 写入成功但新内容无法解析（极少见，如磁盘故障/编码异常） | 检查日志与 `UdiskTools.ini.bak`；程序不会假报保存成功 |
| `[CFG] 恢复默认设置失败` | ini 只读/被占用/目录不可写/写入后校验失败 | 关闭占用程序或检查权限；原 ini 会保留，`.bak` 为覆盖前备份 |

> 路径日志中显示的是**归一化后的绝对路径**（已解析 `.` / `..`），便于直接复制到资源管理器核对。
















## 11. 命令行、单实例、日志与崩溃转储

| 参数 | 说明 | 退出码 |
|---|---|---|
| `--ini <path>` | 指定配置文件（默认 exe 同目录 `UdiskTools.ini`；支持引号与相对路径） | — |
| `--check-ini` | 仅加载校验配置并退出，不建 GUI（适合 CI/现场排查）；成功时输出机型数与**配置文件版本** | 0=成功，1=失败 |
| `--version` / `-v` | 显示**软件版本**（1.2.0）、FileVersion（1.2.0.0）与构建时间后退出（不加载 ini） | 0 |
| `--help` / `-h` / `-?` | 显示用法后退出 | 0 |

- **单实例**：同一用户会话只允许一个 GUI 实例；第二个实例会激活已有窗口后退出（不弹错误框）。用 `--check-ini` 等 CLI 模式不受单实例限制。
- **日志**：`logs\YYYYMMDD.log`（UTF-8）；句柄常驻并允许外部读写/删除；单文件超过 8MB 自动轮转为 `.log.1`；主日志被占用时写 `YYYYMMDD_alt.log`，不会静默丢行；程序退出时安全关闭句柄。
- **崩溃转储**：未处理异常时生成 `logs\crash_YYYYMMDD_HHMMSS.dmp` 并在日志记录异常码/地址/模块；不吞异常。
- **退出码**：0=正常；1=消息循环/初始化失败；3=关窗等待工作线程超时后强制退出（任务可能未完全结束）；CLI `--check-ini` 0/1 见上表。
- **构建资源**：exe 内含版本信息/图标/manifest（Common Controls v6、PerMonitorV2 DPI、longPathAware），资源管理器可直接查看版本（FileVersion 1.2.0.0）。
- **版本区分**：`--version` 显示**软件版本**；**配置文件版本**请用 `--check-ini` 查看，或看窗口标题中的 `v<VERSION>`；两者相互独立。
