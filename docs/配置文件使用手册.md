# UdiskTools 配置文件使用手册

适用版本：v1.0.0（alpha.7 及以上）　配置文件：`UdiskTools.ini`（与 UdiskTools.exe 同目录）

---

## 1. 基本约定

| 项目 | 说明 |
|---|---|
| 文件名 | 必须为 `UdiskTools.ini`，与 exe 同目录 |
| 编码 | UTF-8（推荐）/ UTF-16 / ANSI 自动识别 |
| 注释 | 行内 `;` 之后的内容为注释，会被忽略 |
| 缺失键 | 未写的键取默认值，程序不会报错 |
| 修改生效 | 配置窗口保存后、或切换机型下拉框后**立即重载**，无需重启 |

## 2. 全局节 [TOOLSINFO]

| 键 | 说明 | 默认 |
|---|---|---|
| `TITLE` | 窗口标题 | UdiskTools |
| `VERSION` | 版本号（标题栏+日志） | 1.0.0 |
| `ADMINPASS` | 配置窗口管理员密码；**留空=无密码保护（配置窗口仅只读，不可编辑）** | 空 |
| `PRJNUM` | 机型数量 | — |
| `PRJNAMEn` | 机型 n 的**内部键**，必须与下方机型节名完全一致；程序结构依赖，**永不改动** | — |
| `DISPLAYNAMEn` | 机型 n 的**显示名**（下拉框/配置窗口显示）；可随时修改，不影响程序 | 缺省回退内部键 |
| `DEFAULTMODEL` | 启动时默认选中的机型（内部键） | 第 1 个机型 |

## 3. 机型节（每机型一个节，节名 = 对应 PRJNAMEn）

### 3.1 功能开关（0=禁用：按钮置灰、自动模式跳过）

| 键 | 说明 |
|---|---|
| `ENABLE_READ` | 读取（读取+判定+显示） |
| `ENABLE_WRITE` | 写入（复制文件）；同时控制"写入标签/升级"按钮 |
| `ENABLE_FORMAT` | 格式化 |
| `ENABLE_USBINFO` | USB 通讯模式识别 |
| `AUTORUN` | **1=插入 U 盘立即自动执行任务**；0=仅在"开始监控"开启时插盘自动执行 |
| `AUTO_COPY` | **自动复制开关**：1=自动触发时复制文件（默认 1）；0=自动触发时不复制，只手动点 [复制] 按钮 |
| `AUTO_TEST` | **自动测试开关**：1=自动触发时执行读写测试；0=不自动测试，只手动点 [读写测试]（默认 0） |

> `AUTO_COPY` / `AUTO_TEST` 只影响**自动触发**（插盘）时的动作集合；手动点击按钮不受这两个开关限制。

### 3.2 按钮 ↔ 配置项 ↔ 自动/手动 对照表

| 按钮（控件 ID） | 执行内容 | 相关配置项 | 自动触发时是否执行 |
|---|---|---|---|
| **开始** `IDC_BTN_START 1002` | 完整任务序列：USB 识别 → 复制 → 读取判定 → 读写测试 | `ENABLE_*` / `SRCPATH` / `READFILE` / `READRULE` | —（手动按钮） |
| **停止** `IDC_BTN_STOP 1003` | 中止当前任务 | — | — |
| **复制**（默认名，可配置为“升级”）`IDC_BTN_WRITELABEL 1006` | 仅复制：`SRCPATH→DSTPATH` + MD5 校验，结果显示 `Copy Complete!/Copy Failure!` | `ENABLE_WRITE`、`WRITEMODE=COPY`、`SRCPATH`、`DSTPATH`、`HASH` | 由 `AUTO_COPY` 决定（自动流程内含复制） |
| **读取校验** `IDC_BTN_READCHECK 1015` | 仅读取：通配符匹配 `READFILE` → 读内容 → `READRULE` 判定（关键字/最小长度），结果显示 PASS/FAIL | `ENABLE_READ`、`READFILE`、`MATCH_POLICY`、`READRULE` | 自动流程**总是执行**（核心校验，由 `ENABLE_READ` 控制） |
| **读写测试** `IDC_BTN_RWTEST 1016` | 仅测试：写 8MB→回读→MD5 比对→速率 | 无（通用） | 由 `AUTO_TEST` 决定（1=自动执行） |
| **格式化** `IDC_BTN_FORMAT 1004` | 格式化（FAT32/EXFAT），完成后按 `VOLUME` 写卷标 | `ENABLE_FORMAT`、`CONFIRM`、`FILESYSTEM`、`VOLUME` | 自动流程**不执行**（防误格式化，仅手动） |
| **读取标签** `IDC_BTN_READLABEL 1005` | 读取卷标/文件系统/序列号/容量并显示 | 无 | 自动流程以 USB 识别代替显示 |
| **开始监控 / 停止监控** `1010/1011` | 开启后插盘自动执行完整任务 | 与 `AUTORUN=1` 等效的触发源 | 触发自动流程 |
| **配置** `IDC_BTN_CONFIG 1007` | 打开配置窗口（只读/解锁编辑/恢复默认） | `ADMINPASS` | — |
| **清屏** `IDC_BTN_CLEARCMD 1014` | 清空 CMD-A 显示（日志文件保留） | — | — |

> **自动流程动作集合**（插盘时）：USB 识别（`ENABLE_USBINFO`）→ 复制（`AUTO_COPY=1` 且 `ENABLE_WRITE=1`）→ 读取判定（`ENABLE_READ=1`，总是执行）→ 读写测试（`AUTO_TEST=1`）。格式化永远不自动执行。

### 3.3 按钮显示名（可省略）

| 键 | 默认名 |
|---|---|
| `BTN_START` / `BTN_STOP` / `BTN_FORMAT` / `BTN_READLABEL` / `BTN_WRITELABEL` | 开始 / 停止 / 格式化 / 读取标签 / 写入标签 |

> 说明：`BTN_*` 只改界面文字；内部控件 ID 与日志记录的操作名不变。
> `BTN_WRITELABEL`（如显示为"升级"）实际执行**复制文件**操作。

### 3.4 写入（复制）配置

| 键 | 说明 |
|---|---|
| `WRITEMODE` | `COPY`=简单复制（`PROCESSED` 按台生成不同文件，为后续版本功能） |
| `SRCPATH` | 复制源路径。**支持绝对路径**（`D:\src\*.img`）**和相对路径**（相对 exe 所在目录，如 `.\copy_src\*.*`）；支持通配符 `*` `?` |
| `DSTPATH` | U 盘内目标目录（`\`=根目录）。**目录不存在时自动逐级建立** |
| `HASH` | 校验算法：`md5`（复制前后 MD5 比对，不一致判失败） |

> **覆盖规则**：目标文件已存在时**自动覆盖**（CMD-A 记录"已存在，覆盖"）。

### 3.5 读取（判定）配置

| 键 | 说明 |
|---|---|
| `READFILE` | U 盘上要读取的文件；**支持子目录**（`SYSTEM\PAW6K-LSN`）与**通配符**（`8685????.txt`：固定格式+可变部分，`SYSTEM\*.txt` 两者可组合）；留空=跳过读取 |
| `MATCH_POLICY` | 多个命中时：`NEWEST` 取最新 / `FIRST` 取第一个 / `STRICT` 多命中报错列出全部 |
| `READPATTERN` | `WILDCARD`（`*` `?` 通配符）；`REGEX` 为后续版本支持 |
| `READRULE` | 判定规则链，分号分隔：`MUST_CONTAIN:关键字`（须包含）、`MIN_LEN:10`（最小长度）。判定 PASS 才显示内容并亮绿徽标，FAIL 显示原因并亮红徽标 |

> 命中的可变部分（`?` 对应字符）自动捕获为 `${MATCH_1}`，输出在 CMD-A 日志。

### 3.6 格式化配置

| 键 | 说明 |
|---|---|
| `CONFIRM` | 1=格式化前弹窗二次确认 |
| `FILESYSTEM` | `FAT32` / `EXFAT` |
| `VOLUME` | **格式化完成后**写入的卷标；留空=不改卷标。**没有独立的"写卷标"操作** |

## 4. 路径规则汇总

1. `SRCPATH`：绝对路径与相对路径均支持（相对 = 相对 exe 所在目录）
2. `DSTPATH`：U 盘内路径；多级目录不存在时自动建立（如 `DSTPATH=data\2024\`）
3. 复制目标已存在 → 自动覆盖
4. `READFILE` 支持 U 盘内子目录路径（如 `SYSTEM\PAW6K-LSN` = 读 `U盘:\SYSTEM\PAW6K-LSN`）

## 5. 机型配置示例

```ini
; 新增一个机型的最小步骤：
; ① [TOOLSINFO] 中 PRJNUM 加 1，追加 PRJNAME5=NEWMODEL、DISPLAYNAME5=新机型
; ② 追加机型节：
[NEWMODEL]
ENABLE_READ=1
ENABLE_WRITE=1
ENABLE_FORMAT=0
ENABLE_USBINFO=1
AUTORUN=0
SRCPATH=D:\factory\fw_v2.bin      ; 绝对路径示例
DSTPATH=firmware\                 ; U 盘内 firmware 目录（自动建立）
READFILE=SN*.txt
MATCH_POLICY=NEWEST
READRULE=MUST_CONTAIN:OK;MIN_LEN:5
HASH=md5
```

## 6. 自动复制 / 自动测试如何开启

自动流程由**触发源**与**动作开关**两层控制：

**第一层：触发源（插盘是否自动开始任务）**
1. 机型节内 `AUTORUN=1` —— 插盘即自动跑
2. 或界面点“开始监控” —— 监控期间插盘自动跑

**第二层：动作开关（自动流程包含哪些动作）**
- `AUTO_COPY=1` → 自动复制文件；`0` → 不自动复制（只手动点 [复制]）
- `AUTO_TEST=1` → 自动读写测试；`0` → 不自动测试（只手动点 [读写测试]）
- 读取判定：`ENABLE_READ=1` 时**总是**执行
- 格式化：**永不自动执行**

> 手动点按钮不受 `AUTO_*` 限制（点击即明确意图）。
> 关闭自动：`AUTORUN=0` 并点“停止监控”。

## 7. 恢复默认设置

配置窗口点击 **[恢复默认设置]** 并确认后，程序会用**内嵌的出厂默认配置**（与发布包 `profiles/UdiskTools.ini` 相同）覆盖 `UdiskTools.ini` 并立即重载。自定义过的机型和路径会丢失，请谨慎操作（每次覆盖前有确认弹窗，操作写入日志）。

## 8. 界面状态行与配置窗口

- **状态行**：`AUTO`（绿色）/ `MANUAL`（蓝色）标记 + 其后显示当前机型的 `SRCPATH` 配置值 + 右端**插拔计数器**（`IDC_STC_INSERTCOUNT 1017`）；切换机型或保存配置后立即刷新
- **插拔计数器（`IDC_STC_INSERTCOUNT 1017`）**：仅**监控开启时**计数——每插入一个 U 盘 +1（拔出不计），[停止监控] 即停止计数（数值保留）；显示"**计数:0000**"粗体 4 位数字，**超过 9999 自动回 0000 循环**；启动为 0，退出程序不保存（下次启动自动归零）；启动时已插着的盘不计入
- **标签行（`IDC_STC_LABEL 1101`）**：随插拔**实时刷新**，显示当前各盘卷标 + **USB 硬件标识**（如"标签：F: PHY-32 [VID:0951 PID:1666 SN:001CC0EC34F1…]"），VID/PID 取自 USB 设备描述符、SN 为 USB 序列号——用于**区分同型号的不同个体**；多盘逐个列出；无盘显示"（无磁盘）"；[读取标签] 按钮仍可单独刷新。内置硬盘/读卡器通道取不到 VID/PID 时自动省略该段
- **命中文件提示行分左右**：`IDC_STC_MONFILE 1103` 为**左窗格（1502）专属**提示（第一命中文件路径）；`IDC_STC_MONFILE2 1108` 为**右窗格（1503）专属**提示（第二命中文件路径）；每次插盘同步清空
- **状态徽标（`IDC_STC_ERROR 1202`）双色**：**正常=绿字"✓ …"**（插盘时、任务完成时显示"任务完成"）；**出错=红字"✕ 出错：原因"**（标题栏加 `[!]`）；每次插盘先清掉上一盘状态再显示新盘状态
- **AUTO / MANUAL 判定依据（`IDC_STC_AUTOMODE 1104`）**：
  - **AUTO** = [开始监控] 已开启 **或** 当前机型 `AUTORUN=1` → 插盘会自动执行整任务
  - **MANUAL** = 两者皆无 → 必须手动点按钮
  - `AUTO_COPY` / `AUTO_TEST` 只决定"自动流程内做哪几步"（复制 / 读写测试），**不参与** AUTO/MANUAL 判定；手动点按钮也不会把 AUTO 改成 MANUAL
  - 每次模式变化都写入 CMD-A 日志，便于现场核对，例如 `[UI] 运行模式 AUTO（监控已开启）`、`[UI] 运行模式 AUTO（本机型 AUTORUN=1）`、`[UI] 运行模式 MANUAL（未开监控且本机型 AUTORUN=0）`
- **每次插盘自动刷新**：检测到 U 盘插入时，程序先**熄灭出错徽标**（IDC_STC_ERROR 1202）、**清空 CMD-A**（IDC_EDIT_ENGINE 1401）、**复位进度条与文件内容窗格**，再开始本轮检测/任务日志——每盘信息独立，不会与上一盘混在一起（文件日志 logs\\*.log 仍完整保留全部历史）
- **进度条（`IDC_PBAR_TASK 1301`）**：前方显示"任务进度："提示（`IDC_STC_PROGTITLE 1106`），后方显示实时百分比（`IDC_STC_PROGPCT 1107`）；复制采用 `CopyFileExW` **按字节回调**推进度——复制大文件时进度条实时移动，而不是等整个文件复制完才跳一格
- **文件内容双窗格（左右并排，与 CMD 双控制台同布局）**：左窗格（`IDC_EDIT_FILE 1502`）显示**第一命中文件**内容，右窗格（`IDC_EDIT_FILE2 1503`）显示**第二命中文件**内容（仅一个命中时右窗格为空）；主窗口纵向加高，内容区**不滚动约可见 10 行**
- **配置窗口**：键名用**下拉框**选择（自动列出当前机型全部键）；选中后——
  - 枚举型键（`ENABLE_*`、`AUTO_COPY`、`AUTO_TEST`、`AUTORUN`、`CONFIRM`、`WRITEMODE`、`MATCH_POLICY`、`READPATTERN`、`FILESYSTEM`、`HASH`）自动显示**值下拉框**，无需手输
  - 其余键（`SRCPATH`、`DSTPATH`、`READFILE`、`READRULE`、`VOLUME`、`TITLE` 等）显示**输入框**，自由填写
  - "说明："行（IDC_STC_CFGHINT）实时显示**当前选中键的简要说明**，帮助理解该键含义与可选值；按钮显示名（`BTN_*`）类键与暂未收录的键给出兜底提示（详见本手册对应章节）
  - **键名框支持手动输入**（`IDC_CFG_COMBO_KEY 3011` 为可编辑下拉）：既可从列表选择本机型已有键，也可直接键入**列表外的新键名**（如临时新增一个 `BTN_XXX` 或后续版本预留键），值输入框与新键名配合 [保存修改] 写入 ini；键入手输键名时"说明："行同步给出对应提示或兜底说明

### 8.1 配置窗口键值编辑方式对照表

- **锁定状态**：未解锁时键名/新值控件灰色只读，说明行会提示"点[解锁编辑]输入密码后可修改"

## 9. 安全说明


- `ADMINPASS` 留空时配置窗口永远只读（解锁按钮不可用）
- 密码输入框在点击“解锁编辑”后才显示；连续输错 3 次锁定密码输入
- 解锁/保存/恢复默认等操作均写入日志（不含密码内容）

## 10. 常见错误排查

| CMD-A 提示 | 原因 | 处理 |
|---|---|---|
| `[WRITE] 源目录不存在：D:\...\build\upgrade` | `SRCPATH` 目录名与实际不符（拼写错误/相对路径基准不是 exe 目录） | 核对目录名；相对路径**以 exe 所在目录为基准**，`.\upgrade\*.*` 即 exe 同级的 `upgrade` 文件夹 |
| `[WRITE] 源目录存在，但没有匹配文件（通配符 *.img）` | 目录在，但通配符匹配不到文件 | 检查扩展名/通配符；`*.*` 匹配所有文件 |
| `[WRITE] 源目录内没有可复制的文件` | 目录下只有子文件夹 | 把文件放进该目录，或将 `SRCPATH` 指到实际含文件的目录 |
| `[WRITE] 无法创建目标目录` | U 盘只读/被写保护、路径非法 | 检查写保护开关与 `DSTPATH` 拼写 |
| `[READ] 未找到匹配文件` | 盘内无匹配文件，或 `READFILE` 通配符/路径不符 | 核对文件名规则（如 `8685????.txt`、`SYSTEM\PAW6K-LSN`） |
| `[FORMAT] 格式化失败` | 无权限或盘被占用 | 以管理员身份重试，关闭占用程序 |

> 路径日志中显示的是**归一化后的绝对路径**（已解析 `.` / `..`），便于直接复制到资源管理器核对。
