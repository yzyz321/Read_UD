# UdiskTools 用户使用手册

> 适用软件版本：**v1.2.0**　|　发布形式：单文件 exe，免安装、免运行库　|　系统要求：Windows 7 SP1 及以上（64 位）
> 本手册面向**使用软件的操作员**；配置键的完整参数级说明见《配置文件使用手册》，开发/测试流程见《开发流程》。

---

## 1. 软件是什么

UdiskTools（U盘拷盘工具）是一款 U 盘批量拷盘辅助软件：把源目录的文件自动复制到插入的 U 盘、自动读取盘内指定文件并按规则判定是否合格、对 U 盘做读写测试排查坏块，并支持手动格式化。适合产线/工作室对 U 盘做"拷文件 → 校验 → 标记结果"的重复性操作。

核心能力一览：

| 能力 | 入口 | 说明 |
|---|---|---|
| 复制文件到 U 盘 | 自动流程 / 〔复制〕按钮 | 复制前后 MD5 比对，不一致判失败 |
| 读取并判定盘内文件 | 自动流程 / 〔读取校验〕按钮 | 按判定规则输出 PASS / FAIL |
| 读写测试 | 自动流程 / 〔读写测试〕按钮 | 写 8MB → 回读 → MD5 比对（查坏块） |
| 读取 U 盘信息 | 〔读取标签〕按钮 | 卷标 / 文件系统 / 序列号 / 容量 |
| 格式化 | 〔格式化〕按钮 | 仅手动触发，可配置二次确认；自动流程永不格式化 |
| USB 速度识别 | 自动流程第一步 | 显示 USB 2.0 / 3.x 通讯模式 |

## 2. 安装与启动

1. 将 `udisktools_v1.2.0.exe` 复制到任意目录（U 盘、桌面均可）。
2. 双击运行。程序在 **exe 同目录**读取/生成配置文件 `UdiskTools.ini`。
3. **首次启动（目录里没有 UdiskTools.ini）**会弹出提示：
   - 点【是】：程序自动生成一份默认配置（通用机型）并继续启动——适合先体验；
   - 点【否】：程序直接退出，不生成任何文件——适合先用自己准备好的 ini 替换后再启动。
4. 同一时刻只允许运行一个实例：再次双击只会把已打开的窗口调到前台。

启动后窗口标题形如：`U盘拷盘工具（软件 v1.2.0）（配置 v1.0.0）`——括号里的"软件版本"是程序自身版本，"配置版本"来自 ini 文件，两者独立、互不影响。

## 3. 界面速览

主窗口从上到下：

- **机型下拉框**：选择当前使用的机型方案（对应 ini 中一组配置），切换后立即生效。
- **操作按钮区**：开始、停止、格式化、读取标签、复制、读取校验、读写测试、配置。灰色的按钮表示当前机型未启用该功能或任务执行中。
- **勾选区**：窗口置顶（默认勾选，窗口保持在最前）、自动复制/自动测试（只读显示当前机型设置）、快捷键使能。
- **状态区**：AUTO / MANUAL 模式、监控状态、复制源路径、判定规则、插盘计数。
- **双窗格**：读取校验命中文件的内容显示（左=第一命中，右=第二命中）。
- **CMD-A 日志区**：所有操作的实时日志（绿=正常，黄=警告，红=错误）；【清屏】只清显示，不清文件日志。

## 4. 典型操作

### 4.1 手动拷一个 U 盘
1. 插入 U 盘，在机型下拉框选对机型。
2. 点【复制】（或先【读取标签】确认盘符与容量）。
3. 看 CMD-A 日志与进度条；绿徽标=完成，红徽标=失败（原因见日志）。

### 4.2 开启插盘自动流程（推荐产线用法）
1. 选好机型后点【开始监控】，状态行变为"监控已开启：等待插入…"、模式显示 AUTO（绿）。
2. 此后每插入一个 U 盘自动执行整任务：USB 识别 → 复制 → 读取判定 → 读写测试（哪些步骤执行由机型配置决定）。
3. 结果显示后拔盘、插下一盘即可；插盘计数自动累加。
4. 结束工作点【停止监控】。
- 不开监控也可以：若机型 `AUTORUN=1`，插盘同样自动执行。

### 4.3 读取校验
点【读取校验】：程序在 U 盘内查找配置指定的文件，按判定规则（最小长度/必含关键字）给出 **PASS（绿）**或 **FAIL（红）**，并显示文件内容。

### 4.4 读写测试（查坏块）
点【读写测试】：写 8MB 测试数据→回读→MD5 比对；显示写入/读取速率，不一致提示"可能存在坏块"。

### 4.5 格式化（谨慎）
点【格式化】→（默认）弹窗确认 → 快速格式化为配置指定的文件系统并写卷标。**格式化会清空 U 盘全部数据**；自动流程永远不会格式化。

### 4.6 全局快捷键
勾选"快捷键使能"后（任何窗口下都有效）：
- `Ctrl+Alt+T` = 读写测试；`Ctrl+Alt+C` = 复制。
- 任务执行中按键会被忽略并记录日志。

### 4.7 停止与退出
- 【停止】：中止当前任务（复制会尽量立即取消），结果标记"已停止"。
- 【退出】或点窗口 ×：任务运行中会先询问，等待工作线程收尾（最长 30 秒）。

## 5. 配置窗口（修改机型参数）

1. 点主窗口【配置】按钮打开配置窗口。
2. 配置窗口默认**只读**：左侧选机型，可查看该机型全部键值。
3. 需要修改时点【解锁编辑】：若 ini 设置了 `ADMINPASS`，输入密码解锁；没设密码则提示不支持解锁。
4. 解锁后：键名下拉选键（或手输新键）→ 输入/选择新值 → 【保存修改】（写回 ini 文件，保留原有注释与编码）。
5. 【恢复默认设置】：把 ini 整体恢复为程序内置的默认配置（会先备份为 `UdiskTools.ini.bak`）。
6. 点【关闭】返回主窗口，改动立即生效。
- 密码输错可以无限重试，不会锁定。

## 6. 配置文件（UdiskTools.ini）

- 位置：exe 同目录；UTF-8 编码，可用记事本打开。
- 结构：`[TOOLSINFO]` 全局段（标题、版本、密码、TOPMOST 等）+ 每个机型一个段（如 `[GENERIC]`）。
- 常用键速查（完整说明见《配置文件使用手册》）：

| 键 | 作用 |
|---|---|
| `TITLE` | 主窗口标题文字 |
| `TOPMOST` | 1=启动即窗口置顶（缺省）；0=不置顶 |
| `AUTORUN` | 1=插盘自动执行整任务 |
| `ENABLE_WRITE` / `ENABLE_READ` / `ENABLE_FORMAT` | 复制 / 读取校验 / 格式化 开关（0=按钮置灰） |
| `SRCPATH` / `DSTPATH` | 复制源目录 / U 盘内目标目录 |
| `READFILE` / `READRULE` | 要读取的文件（支持通配符）/ 判定规则 |
| `ADMINPASS` | 配置窗口解锁密码（留空=禁止解锁） |

- 修改 ini 后无需重启：主窗口切换机型或点【配置】→【关闭】都会从磁盘重新加载。

## 7. 常见问题（FAQ）

**Q1 双击后没反应 / 提示已在运行？**
程序已有一个实例在运行，第二个实例会自动激活已有窗口。检查任务栏。

**Q2 启动弹出"配置文件不存在"？**
目录里没有 UdiskTools.ini。要默认配置点【是】；要用自己的配置点【否】退出，把准备好的 ini 放到 exe 同目录再启动。

**Q3 复制按钮是灰的？**
当前机型的 `ENABLE_WRITE=0`。在配置窗口解锁后改为 1，或切换机型。

**Q4 读取校验显示 FAIL：多命中？**
U 盘内有多个文件匹配 `READFILE`。把 `MATCH_POLICY` 改为 NEWEST/FIRST，或清理 U 盘多余文件（STRICT 策略下多命中故意判失败以防拷错盘）。

**Q5 日志提示"目标盘已变化"？**
任务执行中 U 盘被拔插过（防拷错盘保护）。重新插稳后重试。

**Q6 格式化后 U 盘容量不对？**
FAT32 单分区最大 32GB；大于 32GB 的盘请把 `FILESYSTEM` 配置为 EXFAT。

**Q7 想取消窗口置顶？**
取消勾选主窗口"窗口置顶"复选框即可；或把 ini 的 `TOPMOST` 改为 0。

**Q8 出问题了怎么反馈？**
exe 同目录 `logs/` 下有运行日志（含崩溃转储），反馈时请附带。
