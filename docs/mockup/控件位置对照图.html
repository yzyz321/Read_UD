颜色/状态约定
控件状态 → 外观
IDC_BTN_MONSTART 开始监控监控关闭=绿色可用；监控中=浅灰禁用
IDC_BTN_MONSTOP 停止监控监控中=红色可用；监控关闭=浅灰禁用（点击同时中止任务）
IDC_BTN_EXIT 退出常灰可用；任务运行中退出需确认
IDC_STC_ERROR 出错徽标出错=红字"✕ 出错：原因"+标题加[!]；成功/确认后熄灭
IDC_STC_READVERDICT 判定PASS=绿 / FAIL=红
IDC_CHK_HOTKEY 快捷键使能勾选=注册 T/C 全局热键；取消=注销（默认不勾选）
IDC_COMBO_MODEL 机型下拉显示 DISPLAYNAME；切换只影响后续任务（与轮询解耦）
IDC_STC_MONSTATUS 监控状态行"监控已停止"=红色字；"监控已开启"=绿色字；"文件已找到"=黑色字（副行蓝色）
IDC_BTN_CLEARCMD 清屏点击清空 CMD-A（IDC_EDIT_ENGINE）显示内容，文件日志不受影响
IDC_STC_AUTOMODE 状态标记AUTO=绿色（[开始监控]已开启 或 本机型 AUTORUN=1 → 插盘自动执行）；MANUAL=蓝色（两者皆无，须手动点按钮）。由监控开关/AUTORUN 统一推导，手动点按钮不会把它改成 MANUAL；AUTO_COPY/AUTO_TEST 只决定自动流程内做哪几步，不参与本判定。模式变化写日志：如"运行模式 AUTO（监控已开启）"
IDC_STC_SRCPATH 状态行显示当前机型 SRCPATH 配置值；切换机型/保存配置后立即刷新
配置窗口键值编辑键名用下拉选择（IDC_CFG_COMBO_KEY 3011）；枚举键值（ENABLE_*、AUTO_*、WRITEMODE、MATCH_POLICY、READPATTERN、FILESYSTEM、HASH、CONFIRM、AUTORUN）显示为下拉框 IDC_CFG_COMBO_VAL 3012；其余键（SRCPATH、DSTPATH、READFILE、READRULE、VOLUME 等）用输入框 IDC_EDIT_CFGVAL 3009
设备状态 IDC_STC_DEVICE粗体显示；始终由 1s 轮询驱动显示插拔信息，不受监控开/关影响
IDC_BTN_WRITELABEL 复制/升级仅复制（SRCPATH→DSTPATH+MD5）；成功=绿 Copy Complete!，失败=红 Copy Failure!
IDC_BTN_READCHECK 读取校验仅读取+判定（READFILE 通配符 → READRULE 关键字/长度）；PASS 绿 / FAIL 红
IDC_BTN_RWTEST 读写测试仅读写测试（8MB 写读 MD5 比对 + 速率）
自动/手动分配自动触发动作 = USB识别 + 复制(AUTO_COPY=1) + 读取判定(ENABLE_READ 总是) + 测试(AUTO_TEST=1)；格式化永不自动；手动按钮不受 AUTO_* 限制
卷标语义无独立写卷标功能；卷标仅在格式化时按机型 VOLUME 配置写入
※ 已废弃：IDC_STC_MODE（原"○ 待机/模式标记"），自 v1.0.0-alpha.3 起从界面移除。
